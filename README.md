# Web Starter

Універсальний стартовий шаблон для багатосторінкових сайтів на HTML, SCSS і JavaScript. Gulp збирає файли, а BrowserSync запускає локальний сервер з автоматичним оновленням сторінки.

## Вимоги

- Node.js 20 або новіший.
- npm (встановлюється разом із Node.js).

Перевір версії в терміналі:

```bash
node --version
npm --version
```

## Швидкий старт

У терміналі відкрий папку проєкту й виконай:

```bash
npm install
npm run dev
```

BrowserSync відкриє сайт за адресою `http://localhost:3000`. Зміни в HTML, шаблонах, SCSS, JavaScript та статичних ресурсах автоматично потрапляють у `dist/`.

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Очистити `dist/`, зібрати сайт і запустити сервер розробки. |
| `npm run build` | Створити production-збірку в `dist/`, стиснути CSS. Помилки production-збірки виводять діагностику Sass і повертають ненульовий код завершення. У режимі розробки помилки Sass містять назву файлу та рядок, а сервер і спостереження за файлами продовжують працювати. |
| `npm run clean` | Видалити згенеровану папку `dist/`. |

Папка `dist/` створюється автоматично. Не редагуй файли в ній вручну, бо наступна збірка перезапише їх.

├── .gitignore

## Додавання сторінки або HTML-компонента

Створи HTML-файл у `src/`, наприклад `src/about.html`. Gulp обробляє HTML-файли верхнього рівня в `src/`.

Повторювані блоки підключай через `gulp-file-include`:

```html
@@include('templates/header.html')
```

Файл фрагмента має бути в `src/templates/`. Після збірки готовий HTML з'явиться в `dist/` без директив `@@include`.

## SCSS

Починай роботу з `src/scss/style.scss`. Файл підключає модулі через сучасний синтаксис Sass `@use`. У стартері не використовується застарілий `@import`, тому збірка не повинна видавати попередження `Sass @import rules are deprecated`. Додавай нові компоненти в `src/scss/components/`, а потім підключай їх у `style.scss`, наприклад:

```scss
@use 'components/card';
```

Спільні кольори та розміри зберігай у `src/scss/utils/_variables.scss`. Якщо змінна потрібна в іншому SCSS-модулі, імпортуй її через `@use '../utils/variables' as vars;` і звертайся до неї як `vars.$color-primary`.

## Статичні ресурси

Файли з `src/assets/` копіюються в `dist/assets/` без перетворення. Наприклад, `src/assets/images/photo.webp` стане `dist/assets/images/photo.webp`.

## Git

`node_modules/`, `dist/`, локальні файли редакторів і секрети `.env` ігноруються Git. Не зберігай токени, паролі або ключі API в коді, що відправляється у відкрите сховище.

```bash
git init
git add .
git commit -m "Initial web starter"
```

## Перед публікацією

- Заміни назву сайту, заголовки й meta description у HTML.
- Перевір усі посилання, зображення та тексти.
- Перевір сторінку на вузькому екрані та керування лише клавіатурою.
- Запусти `npm run build` і переконайся, що команда завершується без помилок.
- Використовуй HTTPS на хостингу та не додавай до репозиторію приватні ключі.

Цей шаблон не додає сервер, базу даних або форму з реальною відправкою. Таку функціональність потрібно підключити окремо.
